# Suhail: Ages of Arabia, vertical slice ("The Pearl Coast")

Mobile idle civilisation builder across seven ages of Arab history. This repository holds the
vertical slice. Start with [CLAUDE.md](CLAUDE.md).

```
npm install
npm run dev        # open the printed address on a phone on the same network, or in a browser
npm test
npm run build && npm run e2e
```

Status: Phase 2. Core settlement rules and a grey-box town screen work; everything visual is a
placeholder. See [docs/DEVELOPMENT_ROADMAP.md](docs/DEVELOPMENT_ROADMAP.md).
