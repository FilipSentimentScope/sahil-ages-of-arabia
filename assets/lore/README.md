# Painted pages for The Book of Suhail

Drop a painted page here and it replaces the code drawing for that page on the next build.
Name it `lore_<page id>_v<NN>.jpg` (or .png, .webp). Page ids: prologue, age1, age2, age3, age4,
age5, age6, age7, yours. The highest version number is used. Prompts: assets/prompts/LORE_GEMINI_PROMPTS.md.
Each file needs a row in docs/ASSET_INVENTORY.md.
