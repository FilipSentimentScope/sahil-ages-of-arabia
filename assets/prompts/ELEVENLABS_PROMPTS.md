# ElevenLabs prompt sheet (v0.1)

Follows docs/AUDIO_DIRECTION.md. Use a paid plan (Starter or above; free outputs are non-commercial).
Creator ($22/month) is enough for the slice and includes voice design.

How to report results: download each chosen file as `<ID>_v01.mp3` (or WAV if offered) and upload it to
the chat or commit it to `assets/audio/incoming/`. Note the plan, date and prompt for the licence log.

Where a target length is longer than the tool allows, generate the longest it offers; we loop and edit.

## 4. The Rawi's voice (Voice Design, then Text to Speech)

**Voice design prompt**
> An elderly Arab man from the Gulf coast in his seventies, a natural storyteller. Low, warm and unhurried, with a slight rasp and a gentle smile in the voice. Speaks English clearly with a light Gulf Arabic accent. Intimate, as if telling a story to a child by a lantern. Not theatrical, not a movie-trailer voice.

Settings to start from: stability medium-high, style low, speed slightly slow. Generate 3 voice options and send us the samples; we pick one with you.

**First-session lines (English)** from docs/story/STORY_SCRIPT.md. One file per line, `VO-01-<nn>`.
